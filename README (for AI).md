# Стиль чата
В стиле Ripple почти как в теме Moonlit Echoes с портретной аватаркой бота 2:3.

# Цвета 
В основе лежат мягкие тёмно-розовые пастельные цвета, возможно градиент, но я пока не знаю, где именно. Палитра примерно такая: 

- #673a69 (большая часть, предположительно около 60% UI)
- #9a579e (около 20%)
- #b78ab3 (ещё около 20%)

# Идеи и фичи (без лагов)
1. **Карточка сообщения в стиле VN + Ripple** — тёмно-сливовая основа (чуть темнее `#673a69`, чтобы текст легко читался) + тонкая рамка в оттенке `#b78ab3` или двойная рамка без тяжёлых теней.
2. **Бейдж имени персонажа** — имя (`.ch_name`) оформляем аккуратной плашкой с мягким статичным градиентом (`#9a579e` → `#673a69`), как в диалоговом окне визуальной новеллы.
3. **Статичный градиент на верхней панели и поле ввода** — чтобы интерфейс не был плоским, но и не грузил GPU.
4. **Типографика с разделением ролей (по желанию)** — аккуратный пиксельный или моноширинный шрифт только для имени персонажа, заголовков и мелких системных меток, а основной текст ролки — обычным чистым шрифтом, чтобы глаза не уставали.
